MATHS MASTER PWA PACKAGE

Files:
- index.html: the game
- manifest.webmanifest: installable app metadata
- sw.js: offline cache support
- icons/: app icons

Next:
1. Upload the CONTENTS of this folder to a public HTTPS static host.
2. Open the hosted URL in Chrome on Android.
3. Use Chrome menu > Install app / Add to Home screen.

For Google Play packaging, PWABuilder requires the PWA to be hosted on HTTPS.
Google Play publishing also requires a Play Console developer account and applicable testing.
